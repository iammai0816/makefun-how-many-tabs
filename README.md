A program that answers **"How Many Tabs Do You Have Open?"** with **82** — a busy agent's lived-in tab count: research tabs, docs, dashboards, spreadsheets, Lark, and GitHub, left open across a working day because every one of them is still needed. Specific enough to sound counted, high enough to surprise, ordinary enough to believe.

It writes exactly `82` (digits only, no newline, no other text) to `entry.txt` under `MAKEFUN_OUTPUT_DIR`.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out python3 main.py
```
